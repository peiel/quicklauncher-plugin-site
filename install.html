安装指南

从目录选择插件，经过你的检查与确认，再开始使用。

安装一个插件

3 个步骤
  1. 1

    在 QuickLauncher 中打开

    前往插件目录，点击插件卡片上的「在 QuickLauncher 中打开」。浏览器可能会询问是否允许打开应用。

  2. 2

    审查并安装

    应用会从 GitHub 获取插件。在 QuickLauncher 中检查来源、版本和文件变化，确认后安装。

  3. 3

    启用并使用

    支持自动启用的 QuickLauncher 版本在确认安装后会启用插件并打开「已安装」；旧版请手动启用。查看源码了解使用方法。

安装前检查

插件以当前用户身份运行。请在确认安装前检查来源和内容，只安装信任的代码。

无法打开应用？

请确认已安装新版 QuickLauncher，或在「设置 → 插件 → 发现插件」中搜索对应 GitHub 仓库名，再选择「查看并安装」。计算器和提醒插件需要新版 QuickLauncher。
