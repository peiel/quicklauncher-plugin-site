安装指南

在 Mac 上选择插件，检查来源与文件，确认后开始使用。

还没有应用？下载并安装 QuickLauncher。手机可以浏览目录，插件安装请在 Mac 上完成。

安装一个插件

3 个步骤
  1. 1

    在 QuickLauncher 中打开

    前往插件目录，选择「在 QuickLauncher 中打开」。浏览器询问时，允许打开已安装的 QuickLauncher。

  2. 2

    检查后，确认安装

    应用会从 GitHub 获取插件。检查来源、版本和插件文件，确认后才会安装。

  3. 3

    开始使用

    新版 QuickLauncher 会在确认安装后默认启用插件，并切换到「已安装」。在插件详情中查看触发词和用法，也可以随时停用；旧版请先更新应用。

先了解运行方式

插件以当前用户身份运行，可能访问本机文件和网络。请只安装并启用你信任的代码。

支持触发词预览的已启用插件，会在输入匹配时自动执行。被动触发也会自动运行，须插件已启用、规则匹配且独立开关允许；可在插件设置中关闭被动触发。

链接打不开？

先确认已安装新版 QuickLauncher。也可以在「设置 → 插件 → 发现插件」中输入对应 GitHub 仓库名，再选择「查看并安装」。

权限按需授予

选中文字、通知等能力可能需要不同的 macOS 权限。在「设置 → 权限」查看用途，由你决定是否授权。了解系统权限。
