安装密码生成插件

查看 v1.1.0 Release ↗

当前通过 QuickLauncher 内的 GitHub 插件入口安装。安装前可以查看版本、源码和文件变化。

  1. 01
    打开插件设置

    在 QuickLauncher 中进入「设置 → 脚本与插件 → 发现插件」。

  2. 02
    查找并审查插件

    输入下方仓库名，选择「查看并安装」，审查内容后确认。

    peiel/quicklauncher-password-plugin
  3. 03
    启用并使用

    安装后在「已安装」中启用插件。输入 gpwd，或输入 gpwd 32 指定长度。

✳
