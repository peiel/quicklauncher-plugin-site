GET STARTED

安装插件

点击「在 QuickLauncher 中打开」，应用会从 GitHub 获取插件并展示审核内容；确认后才会安装。浏览器可能会询问是否允许打开应用。

  1. 01
    在 QuickLauncher 中打开

    点击插件卡片上的「在 QuickLauncher 中打开」，并在浏览器提示时允许打开应用。

  2. 02
    审查并安装

    在 QuickLauncher 中检查来源、版本和文件变化，确认后安装。

  3. 03
    启用并使用

    安装后在「已安装」中启用插件；查看插件源码了解使用方法。

✳

使用前了解

插件以当前用户身份运行。请只安装信任的代码，并在启用前检查来源和内容。

无法打开应用？请确认已安装新版 QuickLauncher，或在「设置 → 脚本与插件 → 发现插件」中搜索对应 GitHub 仓库名，再选择「查看并安装」。计算器和提醒插件需要新版 QuickLauncher。
